## Where to change it

**Settings → Appearance** holds every appearance choice. Choices take effect
immediately and apply to the current browser only: another browser or device
keeps its own.

## Theme

| Theme | Use |
|---|---|
| Light | Bright working surfaces |
| Dark | Low-light work. Dark mode uses warm near-black surfaces |
| System (the default) | Follows the operating system's setting |

The theme button in the top bar (sun, moon or monitor) cycles Light → Dark →
System without opening Settings.

Every color comes from the theme, so the terminal and the code editor follow it
too.

## Accent color

The accent colors selected navigation, links, focus rings and primary actions.
Each accent is tuned separately for light and dark surfaces.

The twelve accents are Ember (the default), Ocean, Teal, Violet, Orchid, Rose,
Amber, Lime, Cyan, Indigo, Slate and Clay.

## Corners

Corners set how rounded buttons, fields, cards and dialogs are.

| Style | Look |
|---|---|
| Square | No rounding anywhere, including badges and avatars |
| Subtle | Barely softened corners |
| Default | The RivetPanel look |
| Rounded | Soft, generous corners |

## Support tickets

**Support tickets** chooses how Support and the support queue lay out tickets:
Split, Table, Board or Classic list. The switcher on the Support page changes
the same setting. Narrow windows and phones always show the classic list.

What each layout shows is in [Support desk](05-support.md#layouts).
