# Branding

Ready-made RivetPanel images for the places that ask for an app logo.

| File | Size | Upload it to |
| --- | --- | --- |
| `github-app-logo.png` | 512 × 512 | GitHub → Settings → Developer settings → OAuth Apps (or GitHub Apps) → your RivetPanel app → Upload new logo |
| `discord-app-icon.png` | 1024 × 1024 | Discord Developer Portal → Applications → your RivetPanel app → General Information → App icon |
| `rivetpanel-logo.svg` | vector | Anywhere else (docs, a website, a README) |

Both PNGs are full-bleed squares with the mark kept inside the central safe
area, so they survive GitHub's rounded corners and Discord's circular crop.
The web app's own icons (favicons, touch icons, the social preview image) are
in `web/static/`; `web/static/favicon.svg` is the master logo.
