# discord.js starter

1. In the panel, open **Environment** and add `DISCORD_TOKEN` (from the Discord Developer Portal → Bot).
2. Press **Start**. Dependencies are installed automatically on the first start.
3. Invite the bot to a server (OAuth2 → URL Generator → scopes `bot` and `applications.commands`) and run `/ping`.

`rivetpanel.js` sends stats to the panel's Analytics tab once you generate a telemetry key there.
